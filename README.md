## 학생 사용법

1. 아래 표에서 해당 주차의 **"Colab에서 열기"** 배지를 클릭합니다.
2. 코랩이 열리면 **[파일] → [드라이브에 사본 저장]** 을 눌러 **내 구글 드라이브로 복사**합니다.
   - 이 저장소의 원본은 읽기 전용입니다. 사본을 만들어야 편집·저장할 수 있습니다.
3. 로그인 계정이 본인의 **학교 구글 계정(`아이디@kyonggi.ac.kr`)** 인지 오른쪽 위에서 확인합니다.
4. 셀을 실행(`Shift`+`Enter`)하며 실습을 진행합니다.

> 💡 **팁**: 사본을 먼저 저장하지 않으면 작업 내용이 사라질 수 있습니다. **"사본 저장"을 가장 먼저** 하세요.
